# Facts for the Flathub AI disclosure

Flathub's generative AI policy requires the submitter to disclose AI-generated
material in the app and its packaging, naming the affected parts and the
approximate extent, and forbids AI agents from writing the submission pull
request, its description or any review reply. This file is the measured
inventory to write that disclosure from. It is not the disclosure itself.

Measured on 2026-09-08 at tag v0.5.0-beta (144 commits, first commit
2026-08-30):

- Go code: 64,210 lines. 41,997 lines (65 percent) come from commits that
  carry a `Co-Authored-By: Claude` trailer, all dated 2026-09-01 to
  2026-09-08. The remaining 35 percent comes from the 78 commits of
  2026-08-30 and 08-31, which carry no trailer; how those were produced is
  for the author to state.
- Design: the four mockups under `mockup/` are Claude-authored (stated in
  `CLAUDE.md`); the GTK UI was built to match them.
- Store screenshots: captures of the running app on fake data, taken by an
  agent.
- Flathub packaging: the Flatpak manifest and its Flathub variant, the
  AppStream metainfo including release notes, the desktop file, the Nix
  package and the README were written in Claude Code sessions.
  `go.mod.yml` and `modules.txt` were generated by the flatpak-go-mod tool.
- Claude Code session transcripts live under `.agent-shell/transcripts`.

Recount before submitting:

```sh
git log --format='%H' --grep='Co-Authored-By: Claude' | wc -l   # trailer commits
git ls-files '*.go' | xargs wc -l | tail -1                    # total Go lines
```
